## Kurulum

### Windows

1. Zip dosyasini indirin ve acin
2. `mosair.exe` dosyasini calistirin

### macOS

1. `.dmg` dosyasini indirip acin
2. `mosair` uygulamasini **Applications** klasorune surukleyin
3. Uygulamayi Applications'tan (veya Launchpad'den) acin
4. Ilk acilista "Apple dogrulayamadi" uyarisi gelirse **Done**'a basin, sonra:
   **System Settings → Privacy & Security → Open Anyway**
   (Bu islem sadece ilk seferde gerekir.)
